# Data Dictionary

- **SessionID** — Unique website session identifier (Categorical/ID)
- **UserID** — Unique user identifier (Categorical/ID)
- **Timestamp** — Date and time of each recorded interaction (Datetime)
- **PageType** — Page visited during the interaction (Categorical)
- **DeviceType** — Device category used for the session (Categorical)
- **Country** — User country (Categorical)
- **ReferralSource** — Acquisition/referral source (Categorical)
- **TimeOnPage_seconds** — Time associated with the page interaction (Numeric)
- **ItemsInCart** — Number of items in cart at the event (Numeric)
- **Purchased** — Purchase indicator (0/1) (Binary)
